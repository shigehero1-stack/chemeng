反応速度の解析法

回分実験で測った濃度と時間のデータから、反応次数と速度定数を決める方法として、積分法、微分法、半減期法、初速度法の手順と使い分けを、同じデータを使った例題で解説します。

速度式は実験で決める

反応速度と反応次数の記事で見たように、反応速度は $-r_A = k\,C_A^{\,n}$ のような速度式で表します。反応器を設計するには、この反応次数 $n$ と速度定数 $k$ が必要ですが、これらは化学反応式の係数からは決まらず、実験で求めるしかありません。

最もよく使われるのは、温度を一定にした回分反応器で、時間とともに濃度がどう減るかを測る実験です。この記事では、そのデータから $n$ と $k$ を決める代表的な方法を、同じデータを使って比べます。

例題のデータ

温度一定の回分反応器で、A → 生成物 の液相反応を行い、A の濃度を測りました。

時間 [min]024681015203040
$C_A$ [mol/L]2.001.651.431.241.101.010.790.660.500.40

このデータから、反応次数と速度定数を求めます（データは当サイトで作った説明用のものです）。

方法1：積分法

反応次数を仮定し、回分反応器の設計式を積分した式がデータに合うかどうかを確かめる方法です。回分反応器の設計式を積分すると、次のようになります。

仮定する次数積分した式縦軸にとる量直線の傾き
0次$C_A = C_{A0} - k t$$C_A$$-k$
1次$\ln C_A = \ln C_{A0} - k t$$\ln C_A$$-k$
2次$\dfrac{1}{C_A} = \dfrac{1}{C_{A0}} + k t$$1/C_A$$k$

仮定した次数が正しければ、表の量を時間に対して描くと直線になります。直線になれば、傾きから速度定数が求まります。

例題での結果

  • $\ln C_A$ を描くと、点ははっきりと下に凸に曲がります。1次ではありません
  • $1/C_A$ を描くと、すべての点がほぼ1本の直線に乗ります。最小二乗法で直線を当てはめると、傾き $k$ = 0.0500 L/(mol·min)、切片 0.504 L/mol（$1/C_{A0}$ = 0.500 とよく一致）、決定係数 0.9999 です
1次と仮定した場合も、直線を当てはめると決定係数は 0.949 になります。決定係数だけを見ると「まあまあ合っている」ように見えますが、図を描くと、点が直線の上下に規則的に（曲がって）並んでいることがわかります。当てはまりの判断は、数値だけでなく必ず図と残差の並び方で行うのが原則です。

積分法は、データのばらつきに強く、次数が整数（0、1、2）のときに最も使いやすい方法です。一方、次数が 1.5 のような半端な値の場合には、何回も仮定し直す必要があります。

方法2：微分法

反応速度そのものをデータから求め、速度式 $-r_A = k\,C_A^{\,n}$ に直接当てはめる方法です。両辺の対数をとると

$$\ln(-r_A) = \ln k + n\,\ln C_A$$

となり、$\ln(-r_A)$ を $\ln C_A$ に対して描いた直線の傾きが反応次数、切片から速度定数が求まります。次数を仮定する必要がないのが利点です。

反応速度は、隣り合う2点の差から求めます。区間の平均濃度での速度とみなして

$$-r_A \approx -\frac{C_{A,i+1} - C_{A,i}}{t_{i+1} - t_i}, \qquad C_A \approx \frac{C_{A,i} + C_{A,i+1}}{2}$$
区間 [min]0〜22〜44〜66〜88〜1010〜1515〜2020〜3030〜40
平均濃度 [mol/L]1.8251.5401.3351.1701.0550.9000.7250.5800.450
速度 [mol/(L·min)]0.1750.1100.0950.0700.0450.0440.0260.0160.010

両対数で直線を当てはめると、傾き $n$ = 2.02、速度定数 $k$ = 0.0492 L/(mol·min) となり、積分法の結果と一致します。

表を見ると、8〜10 分と 10〜15 分の速度がほとんど同じになるなど、点が積分法より大きくばらついています。差をとると、濃度の測定誤差が拡大されるためです。微分法は次数の見当をつけるのに便利で、最終的な速度定数は積分法で決める、という使い分けがよく行われます。データが多い場合は、点を滑らかな曲線で近似してから微分すると、ばらつきを抑えられます。

方法3：半減期法

$n$ 次反応（$n \ne 1$）では、濃度が半分になるまでの時間（半減期）は、そのときの濃度によって次のように変わります。

$$t_{1/2} = \frac{2^{\,n-1} - 1}{(n - 1)\,k}\,C_{A0}^{\,1-n}$$

1次反応では半減期は濃度によらず一定、2次反応では濃度に反比例します。例題のデータでは

  • 2.00 → 1.00 mol/L：約 10 分
  • 1.00 → 0.50 mol/L：約 30 − 10 = 20 分

濃度が半分になると半減期が2倍になっているので、$C_{A0}^{\,1-n}$ の関係から $2^{\,n-1} = 2$、すなわち $n$ = 2 です。2次反応の半減期の式 $t_{1/2} = 1/(k\,C_{A0})$ から、$k = 1/(10 \times 2.00) = 0.050$ L/(mol·min) も求まります。図に描かなくても次数の見当がつく、手軽な方法です。

方法4：初速度法

初濃度を変えた実験を何回か行い、それぞれの反応の始めの速度（初速度）を比べる方法です。初濃度を2倍にしたとき初速度が4倍になれば2次、2倍なら1次です。反応の始めだけを使うので、生成物が反応を妨げる（逆反応や阻害が起こる）場合でも、その影響を受けにくいのが利点です。

原料が2種類ある反応 $-r_A = k\,C_A^{\,a}\,C_B^{\,b}$ では、一方の濃度を一定にして他方だけを変える実験を組み合わせて、$a$ と $b$ を別々に決めます。一方の原料を大過剰にして、その濃度が実質的に変わらないようにする方法（過剰法、擬次数の方法）もよく使われます。

方法の使い分け

方法利点注意点
積分法データのばらつきに強い。速度定数を精度よく決められる次数を仮定する必要がある。半端な次数には向かない
微分法次数を仮定せずに直接求められる差をとるのでばらつきが大きくなる。データの間隔に注意
半減期法手軽に次数の見当がつく半減期を読み取る精度に左右される
初速度法生成物の影響を受けにくい。複数の原料の次数を分けて決められる実験の回数が多くなる

速度定数の温度依存性

反応器の設計では、いくつかの温度で同じ実験を行い、温度ごとの速度定数から活性化エネルギーと頻度因子を求めます。$\ln k$ を $1/T$ に対して描くアレニウスプロットの直線の傾きが $-E/R$ になります。手順は反応速度とアレニウスの式の記事を参照してください。

実験と解析での注意

  • 温度を一定に保つ：発熱の大きい反応では、反応の始めに温度が上がって速度が速く見えることがある。反応液を薄めるか、冷却を強める
  • 反応を止めてから分析する：サンプルを取ってから分析するまでに反応が進むと、濃度を低く測ってしまう。冷却や中和で反応を止める
  • 反応率の広い範囲のデータをとる：反応率が低い範囲のデータだけでは、どの次数でもほぼ直線に見えて区別できない。反応率 70〜80% 程度までのデータがあると判断しやすい
  • 物質移動の影響を除く：固体触媒や気液反応では、測った速度が反応ではなく拡散の速さで決まっていることがある。撹拌の強さや触媒の粒径を変えても速度が変わらないことを確かめる（触媒有効係数の記事を参照）
