伝達関数とブロック線図

伝達関数とブロック線図の基本、二次遅れ系の減衰係数、比例制御のオフセット、特性方程式による安定性の判定を例題とシミュレーションで解説します。

この記事で学ぶこと

このサイトの基本の記事では、一次遅れ系のステップ応答を微分方程式から求めました。プロセスがいくつもつながったり、制御装置と組み合わさったりすると、微分方程式を直接扱うのは大変になります。そこで制御工学では、伝達関数とブロック線図という道具を使って、入力と出力の関係を代数計算で扱います。

この記事では、伝達関数の考え方、二次遅れ系の特徴、ブロック線図による閉ループの計算、そして制御系が不安定になる条件を学びます。「PID 制御の設計」の記事の PID 制御の設計の土台になります。

伝達関数

時間の関数をラプラス変換すると、微分は $s$ を掛けることに置きかわります。初期値を0（平衡状態からの変化分）として一次遅れ系の式 $\tau\,dy/dt + y = K u$ を変換すると

$$(\tau s + 1)\,Y(s) = K\,U(s) \quad\Rightarrow\quad G(s) = \frac{Y(s)}{U(s)} = \frac{K}{\tau s + 1}$$

となります。この $G(s)$ を伝達関数といいます。入力と出力の関係が「掛け算」で表せるので、要素を組み合わせたときの計算が簡単になります。

要素伝達関数
比例（ゲイン）$K$
一次遅れ$\dfrac{K}{\tau s + 1}$
むだ時間$e^{-\theta s}$
積分（液面など）$\dfrac{K}{s}$
二次遅れ$\dfrac{K}{\tau^2 s^2 + 2\zeta\tau s + 1}$

最終値の定理：ステップ入力（大きさ1）に対する最終的な出力は、$\lim_{s \to 0} G(s)$ で求められます。これを使うと、応答を全部計算しなくても定常値がわかります。

直列につながった要素

要素が直列につながっているときは、全体の伝達関数は各要素の伝達関数の積になります。たとえば、互いに影響しない2つの槽（前の槽の流出が後の槽に流れ込むだけ）が直列にある場合

$$G(s) = \frac{K_1}{\tau_1 s + 1}\cdot\frac{K_2}{\tau_2 s + 1}$$

で、二次遅れ系になります。一次遅れを重ねると、応答の立ち上がりがゆるやかな S 字形になり、むだ時間があるように見えます。高次の系を「一次遅れ＋むだ時間」で近似できるのはこのためです。

二次遅れ系と減衰係数

二次遅れ系のふるまいは、減衰係数 $\zeta$ で決まります。

  • $\zeta > 1$（過減衰）：振動せず、ゆっくり目標に近づく。一次遅れの直列はこの形
  • $\zeta = 1$（臨界減衰）：振動しない範囲で最も速い
  • $\zeta < 1$（不足減衰）：行き過ぎて振動しながら落ち着く

不足減衰のときのステップ応答の行き過ぎ量とピーク時間は

$$\text{行き過ぎ量} = \exp\left(-\frac{\pi\zeta}{\sqrt{1 - \zeta^2}}\right), \qquad t_p = \frac{\pi\,\tau}{\sqrt{1 - \zeta^2}}$$

です。プロセスそのものが二次遅れで振動的になることは少ないのですが、制御をかけた閉ループの応答はしばしば二次遅れに近い形になり、この関係が調整の目安に使われます。

ブロック線図と閉ループの伝達関数

フィードバック制御系は、次の要素のブロック線図で表せます。

  • 調節計 $G_c(s)$（比例制御なら $K_c$）
  • プロセス $G_p(s)$
  • 目標値 $R(s)$、制御量 $Y(s)$、偏差 $E = R - Y$

偏差を調節計に入れ、その出力をプロセスに入れ、出力を戻して目標値と比べる、というループをたどると、目標値から制御量までの閉ループの伝達関数は

$$\frac{Y(s)}{R(s)} = \frac{G_c G_p}{1 + G_c G_p}$$

になります。分母の $1 + G_c G_p$ が、閉ループの性質（安定かどうか、どれだけ速いか）を決めます。

例題1：比例制御のオフセット

ゲイン $K$ = 2、時定数 5 のプロセスを比例制御します。目標値を1だけ上げたとき、制御量は最終的にいくらになりますか。

解答

閉ループの伝達関数に最終値の定理を使うと

$$y(\infty) = \lim_{s\to 0}\frac{K_c K/(\tau s + 1)}{1 + K_c K/(\tau s + 1)} = \frac{K_c K}{1 + K_c K}$$

比例ゲインを上げるとオフセットは小さくなりますが、ゼロにはなりません。このサイトの基本の記事で説明した「比例動作だけではオフセットが残る」ことが、式で確かめられます。

安定性：特性方程式

閉ループの伝達関数の分母を0とおいた式

$$1 + G_c(s)\,G_p(s) = 0$$

を特性方程式といいます。この式の根（極）の実部がすべて負なら安定、1つでも正があれば不安定です。多項式の根を直接求めなくても、ラウスの安定判別法などで、安定かどうかを係数から判定できます。

例題2：3つの槽を直列にしたプロセスの限界ゲイン

時定数 1、ゲイン 1 の一次遅れが3つ直列につながったプロセスを、比例制御します。制御系が不安定になる比例ゲインを求めてください。

解答

$G_p = 1/(s + 1)^3$ なので、特性方程式は

$$(s + 1)^3 + K_c = s^3 + 3s^2 + 3s + 1 + K_c = 0$$

です。安定の限界では、特性方程式が純虚数の根 $s = j\omega$ をもちます。代入して実部と虚部をそれぞれ0とおくと

  • 虚部：$-\omega^3 + 3\omega = 0 \Rightarrow \omega = \sqrt{3}$
  • 実部：$-3\omega^2 + 1 + K_c = 0 \Rightarrow K_c = 8$

したがって、比例ゲインが 8 を超えると不安定になります。限界ゲインでの振動の周期は $2\pi/\sqrt{3} \approx 3.63$ です。

一次遅れ1つや2つでは、比例ゲインをいくら上げても理論上は不安定になりませんが、3つ以上重なる（または、むだ時間がある）と、ゲインを上げすぎたときに不安定になります。これが、このサイトのPID 制御のパラメータ調整の記事で紹介したジーグラー・ニコルスの限界感度法の「持続振動」の正体です。

検算について

この記事の数値は、検算用に作成したプログラム（Python）で、微分方程式を4次のルンゲ・クッタ法で数値積分して確かめています。二次遅れの行き過ぎ量とピーク時間は式と数値解が一致し（例：$\zeta$ = 0.5 で 16.3%、3.63）、比例制御の最終値も式と一致しました。3槽直列の例では、$K_c$ = 6 で振動が減衰し、$K_c$ = 8 で一定の振幅の振動が続き（周期 3.628、理論値 3.628）、$K_c$ = 10 で発散することを確認しています。
