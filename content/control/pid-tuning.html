パラメータ調整（チューニング）とは

PID制御では、比例ゲイン $K_p$、積分時間 $T_i$、微分時間 $T_d$ の3つの値を、制御するプロセスに合わせて決める必要があります。この作業をチューニングといいます。

値が小さすぎると反応が鈍く、外乱からの回復に時間がかかります。大きすぎると行き過ぎや振動が起こり、最悪の場合は制御が不安定になります。

ジーグラー・ニコルスの限界感度法

実際の制御ループを使って調整する、古くから知られた方法です。

  1. 積分動作と微分動作を止め、比例動作だけにする
  2. 比例ゲインを小さい値から少しずつ上げていく
  3. 制御量が一定の振幅で振動し続ける（持続振動）ときのゲインを限界ゲイン $K_u$、振動の周期を限界周期 $P_u$ として記録する
  4. 次の表から各パラメータを計算する
制御の種類$K_p$$T_i$$T_d$
P$0.5\,K_u$――
PI$0.45\,K_u$$P_u / 1.2$―
PID$0.6\,K_u$$0.5\,P_u$$0.125\,P_u$
例題：限界感度法によるPIDパラメータ

ある温度制御ループで比例ゲインを上げていったところ、$K_u = 4.0$ で周期 60 秒の持続振動が起こりました。PI制御とPID制御のパラメータを求めてください。

PI制御：$K_p = 0.45 \times 4.0 = 1.8$、$T_i = 60 / 1.2 = 50\ \text{s}$

PID制御：$K_p = 0.6 \times 4.0 = 2.4$、$T_i = 0.5 \times 60 = 30\ \text{s}$、$T_d = 0.125 \times 60 = 7.5\ \text{s}$

限界感度法は、実際のプロセスを意図的に振動させる必要があります。安全上や品質上それが許されないプロセスでは使えないので、次のステップ応答法やモデルを使った方法を選びます。

ステップ応答法

制御をかけない状態（手動）で操作量をステップ状に変え、制御量の応答曲線を記録します。応答を一次遅れ＋むだ時間とみなして、ゲイン $K$、時定数 $\tau$、むだ時間 $L$ を読み取り、それをもとにパラメータを計算します。ジーグラー・ニコルスのステップ応答法や、より振動の少ない応答を狙ったCHR法、内部モデル制御（IMC）にもとづく方法など、いくつかの計算式が提案されています。

調整後の微調整

ジーグラー・ニコルスの方法で求めた値は、外乱をすばやく抑えることを重視した「やや振動的」な設定になりがちです。実際には、得られた値を出発点にして、応答を見ながら次のように微調整します。

  • 振動が大きい：比例ゲインを下げる、積分時間を長くする
  • 目標値に戻るのが遅い：比例ゲインを上げる、積分時間を短くする
  • 行き過ぎが大きい：微分時間を少し加える（ノイズが多い場合は注意）

一度にたくさんのパラメータを変えず、1つずつ変えて効果を確かめるのがコツです。

よくある間違い

  • 比例帯とゲイン：調節計によっては比例ゲイン $K_p$ ではなく比例帯 $PB = 100 / K_p$ [%] で設定します。$K_p = 2$ なら比例帯は 50% です。値を大きくしたときの効き方が逆になるので注意します。
  • 積分時間と積分ゲイン：積分時間 $T_i$ を長くすると積分動作は弱くなります。積分ゲインで設定する機種では $K_i = K_p / T_i$ の関係があります。
  • 秒と分：$T_i$・$T_d$ の単位が秒か分かは、調節計のメーカーや機種で違います。60倍ずれると、ほとんど効かないか、激しく振動します。
  • 限界感度試験の危険：持続振動を起こす試験は、実際のプラントでは製品や安全に影響することがあります。振幅を小さく抑えるか、ステップ応答法やモデルにもとづく方法（PID 制御の設計）を使います。

練習問題

練習：限界感度法でパラメータを決める

ある流量制御ループで、比例ゲインを上げていくと $K_u = 2.5$ で周期 $P_u = 120$ 秒の持続振動が起こりました。(1) P制御、(2) PI制御、(3) PID制御のパラメータを求めてください。PID制御の比例帯も答えてください。

(1) P制御：$K_p = 0.5 \times 2.5 = 1.25$

(2) PI制御：$K_p = 0.45 \times 2.5 \approx 1.13$、$T_i = 120 / 1.2 = 100\ \text{s}$

(3) PID制御：$K_p = 0.6 \times 2.5 = 1.5$、$T_i = 0.5 \times 120 = 60\ \text{s}$、$T_d = 0.125 \times 120 = 15\ \text{s}$。比例帯は $100 / 1.5 \approx 67\%$ です。

ジーグラー・ニコルスの値は振動しやすめなので、実際にはここから $K_p$ を少し下げて様子を見ます。
