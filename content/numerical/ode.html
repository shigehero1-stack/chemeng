化学工学と常微分方程式

回分反応器の濃度変化、槽の温度の時間変化、管型反応器の中の温度分布など、化学工学の多くの問題は常微分方程式で表されます。簡単な場合は式で解けますが、反応が複数あったり、温度で速度が変わったりすると、式では解けなくなります。そこで使うのが数値解法です。

オイラー法

$\dfrac{dy}{dt} = f(t, y)$ を解くとき、今の傾きがしばらく続くとみなして、刻み幅 $h$ だけ先の値を求めます。

$$y_{n+1} = y_n + h\,f(t_n, y_n)$$

最も簡単ですが、誤差は刻み幅に比例して（1次の精度）しか小さくならないため、正確な答えを得るにはとても細かい刻みが必要です。

4次のルンゲ・クッタ法

1つの刻みの中で4か所の傾きを計算し、重みをつけて平均します。

$$y_{n+1} = y_n + \frac{h}{6}\left(k_1 + 2k_2 + 2k_3 + k_4\right)$$

$k_1$ は区間の始め、$k_2$ と $k_3$ は区間の中央、$k_4$ は区間の終わりでの傾きです。誤差は刻み幅の4乗に比例して小さくなり、同じ刻み幅でもオイラー法よりはるかに正確です。実用的な計算の標準的な方法です。

例題：逐次反応の濃度変化

逐次反応 A → B → C（速度定数 $k_1$ = 0.2 1/min、$k_2$ = 0.1 1/min、最初は A だけで濃度1）で、B の濃度が最大になる時刻（約 6.93 分）の B の濃度を、オイラー法とルンゲ・クッタ法で計算し、厳密解（0.5）と比べてください。

成分 A と B の収支は次のとおりです。

$$\frac{dC_A}{dt} = -k_1 C_A, \qquad \frac{dC_B}{dt} = k_1 C_A - k_2 C_B$$
import math

k1, k2 = 0.2, 0.1                    # A -> B -> C の速度定数 [1/min]

def f(y):
    A, B = y
    return [-k1 * A, k1 * A - k2 * B]

def euler(y, h, n):
    for _ in range(n):
        d = f(y)
        y = [y[i] + h * d[i] for i in range(2)]
    return y

def rk4(y, h, n):
    for _ in range(n):
        a = f(y)
        b = f([y[i] + h / 2 * a[i] for i in range(2)])
        c = f([y[i] + h / 2 * b[i] for i in range(2)])
        d = f([y[i] + h * c[i] for i in range(2)])
        y = [y[i] + h / 6 * (a[i] + 2 * b[i] + 2 * c[i] + d[i]) for i in range(2)]
    return y

t_end = math.log(k2 / k1) / (k2 - k1)            # 解析解で B が最大になる時間
exact = k1 / (k2 - k1) * (math.exp(-k1 * t_end) - math.exp(-k2 * t_end))
for n in [7, 14, 70]:
    h = t_end / n
    print(f"刻み {h:.2f} min: オイラー {euler([1.0, 0.0], h, n)[1]:.5f}, "
          f"ルンゲ・クッタ {rk4([1.0, 0.0], h, n)[1]:.5f}, 厳密解 {exact:.5f}")

実行結果：

刻み 0.99 min: オイラー 0.53723, ルンゲ・クッタ 0.49999, 厳密解 0.50000
刻み 0.50 min: オイラー 0.51786, ルンゲ・クッタ 0.50000, 厳密解 0.50000
刻み 0.10 min: オイラー 0.50346, ルンゲ・クッタ 0.50000, 厳密解 0.50000

刻みが約 1 分のとき、オイラー法の誤差は 7% もありますが、ルンゲ・クッタ法はすでに小数第4位まで正確です。オイラー法の誤差は、刻みを半分にするとほぼ半分にしかなりません。

数値解法を使うときの注意

  • 刻み幅を変えて結果を比べる：刻み幅を半分にしても答えがほとんど変わらなければ、十分に細かいと判断できます
  • 硬い（stiff）問題：非常に速い反応と遅い反応が混ざった系では、普通の方法だと極端に細かい刻みが必要になります。その場合は、硬い問題向けの解法（陰解法）を使います
  • ライブラリの利用：実務では、刻み幅を自動で調整してくれる数値計算ライブラリ（Python なら SciPy の solve_ivp など）を使うのが一般的です。ただし、しくみを知っておくと、結果がおかしいときに原因を見つけやすくなります
