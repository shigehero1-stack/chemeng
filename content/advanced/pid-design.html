13.1 この章で学ぶこと

このサイトの基本の記事では、ジーグラー・ニコルスの限界感度法で PID のパラメータを決める方法を紹介しました。この方法は手軽ですが、実際に使ってみると「振動が大きすぎる」と感じることが少なくありません。

本章では、プロセスのモデル（一次遅れ＋むだ時間）から PID のパラメータを計算するモデルにもとづくチューニングを学びます。代表として、内部モデル制御（IMC）の考え方から導かれた SIMC 法を取り上げ、ジーグラー・ニコルスの方法と、シミュレーションで性能を比べます。

13.2 プロセスモデルを求める：一次遅れ＋むだ時間

制御をかけない状態（手動）で操作量をステップ状に変え、制御量の応答を記録します。この応答を、次の3つのパラメータで表します。

  • ゲイン $K$：操作量を1変えたとき、最終的に制御量がどれだけ変わるか
  • 時定数 $\tau$：変化の速さ
  • むだ時間 $\theta$：操作してから制御量が動き始めるまでの時間
$$\frac{y(s)}{u(s)} = \frac{K\,e^{-\theta s}}{\tau s + 1}$$

高次の遅れをもつプロセスも、応答曲線の形に合わせてこの形に近似するのが一般的です。むだ時間と時定数の比 $\theta / \tau$ が大きいほど、制御は難しくなります。

13.3 IMC の考え方

IMC（内部モデル制御）は、「目標値を変えたとき、制御量がどのような応答をしてほしいか」を先に決め、それを実現するコントローラーを逆算する考え方です。一次遅れ＋むだ時間のプロセスでは、望む応答を「むだ時間のあと、時定数 $\tau_c$ の一次遅れで目標値に近づく」とすると、その応答を実現するコントローラーが近似的に PI 制御になります。

$\tau_c$ は、設計者が選ぶ唯一の調整つまみです。

  • $\tau_c$ を小さくすると、応答は速くなるが、モデルの誤差に弱くなり、操作量の動きが激しくなる
  • $\tau_c$ を大きくすると、応答はゆっくりになるが、安定で頑丈になる

13.4 SIMC 法のチューニング式

IMC の考え方をもとに、実用的に整理された SIMC 法（スコゲスタッドの方法）の PI パラメータは次のとおりです。

$$K_c = \frac{1}{K}\cdot\frac{\tau}{\tau_c + \theta}, \qquad T_i = \min\{\tau,\ 4(\tau_c + \theta)\}$$

$\tau_c$ の標準的な選び方は $\tau_c = \theta$ です。これで、速さと頑丈さのバランスがとれた設定になるとされています。

積分時間の式の $\min$ は、時定数が非常に長いプロセス（積分に近いプロセス）で、外乱からの回復が遅くなりすぎないようにするための工夫です。

13.5 比較のための他の方法

ジーグラー・ニコルスのステップ応答法では、同じ3つのパラメータから次のように決めます。

制御の種類$K_c$$T_i$$T_d$
PI$0.9\,\tau / (K\theta)$$3.33\,\theta$―
PID$1.2\,\tau / (K\theta)$$2\,\theta$$0.5\,\theta$

13.6 例題：シミュレーションによる比較

ゲイン $K$ = 2.0、時定数 $\tau$ = 10 min、むだ時間 $\theta$ = 2 min のプロセスを考えます。次の2つの場面で、各方法の性能を比べます。

1. 時刻 0 で目標値を 1 だけ上げる（目標値追従） 2. 時刻 60 min で、操作量の入口側に大きさ −0.5 の外乱が入る（外乱抑制）

パラメータの計算

SIMC 法（$\tau_c = \theta = 2$ min）：

$$K_c = \frac{1}{2.0}\cdot\frac{10}{2 + 2} = 1.25, \qquad T_i = \min\{10,\ 16\} = 10\ \text{min}$$

ジーグラー・ニコルスの PI：$K_c = 0.9 \times 10 / (2.0 \times 2) = 2.25$、$T_i = 6.67$ min

ジーグラー・ニコルスの PID：$K_c = 3.0$、$T_i = 4.0$ min、$T_d = 1.0$ min

シミュレーション結果

IAE は、目標値からのずれの絶対値を時間で積分したもので、小さいほど良い制御です。

結果の読み方

  • 目標値追従では、SIMC 法（標準）が行き過ぎ 4%、整定 6.7 分と、最もバランスのよい応答になりました。ジーグラー・ニコルスの方法は行き過ぎが 50% を超え、振動的です
  • 外乱抑制では、逆にジーグラー・ニコルスの方法のほうがずれが小さく、早く回復します。強い（ゲインが大きい）設定ほど外乱には強いためです
  • SIMC 法の $\tau_c$ を小さくすると、外乱には強くなりますが、目標値追従の行き過ぎが増えます

つまり、目標値追従と外乱抑制はトレードオフの関係にあり、「どの方法が一番良いか」はプロセスで何を重視するかによって変わります。化学プロセスでは目標値を変えることは少なく、外乱を抑えることが主な役割である制御ループが多いため、外乱抑制を重視して $\tau_c$ を小さめにとることもあります。一方、ジーグラー・ニコルスの設定はむだ時間やプロセスの特性が変わったときに不安定になりやすいので、そのまま使うのではなく出発点として微調整するのが無難です。

13.7 目標値と外乱の両方をよくする工夫

  • 目標値の重み付け（2自由度 PID）：比例動作を「目標値 − 制御量」ではなく「$b$ × 目標値 − 制御量」（$0 \le b \le 1$）に対してかける。外乱に強い設定のまま、目標値を変えたときの行き過ぎを抑えられる。多くの調節計に機能として備わっている
  • 微分動作を測定値にかける：目標値を急に変えたときに、微分動作で操作量が跳ね上がるのを防ぐ（本章のシミュレーションでもこの方式を使用）

13.8 カスケード制御

反応器の温度を、ジャケットの冷却水の弁で制御する場合を考えます。冷却水の温度や圧力が変わると、弁の開度が同じでも冷却の強さが変わり、それが反応器の温度に現れるまでには大きな遅れがあります。

カスケード制御では、反応器温度の調節計（外側のループ）がジャケット温度の目標値を決め、ジャケット温度の調節計（内側のループ）が弁を操作します。冷却水側の外乱は、反応器の温度に影響が出る前に内側のループで素早く打ち消されます。内側のループは外側より十分に速い（目安として3倍以上）必要があり、チューニングは内側から先に行います。

13.9 検算について

本章のシミュレーションは、検算用プログラム（check_ch13.py）で行っています。一次遅れ＋むだ時間のプロセスを 0.001 分の刻みで数値積分し、各方法の PI・PID 制御を組み合わせて、行き過ぎ量・整定時間・IAE を計算しました。微分動作は測定値にかけ、微分時間の 1/10 の時定数のフィルタをつけています。フィルタの設定などによって数値は多少変わりますが、方法どうしの傾向は変わりません。
