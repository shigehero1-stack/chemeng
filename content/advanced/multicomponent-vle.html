1.1 この章で学ぶこと

このサイトの基本の記事では、2成分系の気液平衡をラウールの法則で計算し、x-y 線図で表しました。実際のプロセスで扱う液体は3成分以上を含むことがほとんどで、図ではなく計算で気液平衡を扱う必要があります。

本章では、多成分系の気液平衡の3つの基本計算である沸点計算・露点計算・フラッシュ計算を、手順どおりに解けるようになることを目指します。後半では、ラウールの法則が成り立たない非理想系を活量係数で扱う方法と、共沸が生まれるしくみを見ます。第2章の多成分蒸留の設計は、本章の計算が土台になります。

1.2 K値

多成分系の気液平衡は、各成分のK値（気液平衡比）で表すと見通しがよくなります。

$$K_i = \frac{y_i}{x_i}$$

$K_i > 1$ の成分は気相に、$K_i < 1$ の成分は液相に多く分配されます。気相を理想気体、液相を理想溶液とみなせる（ラウールの法則が成り立つ）場合は

$$K_i = \frac{p_i^{\text{sat}}(T)}{P}$$

で、温度と圧力だけで決まり、組成によりません。これが計算を簡単にしてくれます。

1.3 沸点計算と露点計算

沸点（泡点）は、液を加熱していって最初の泡ができる温度です。液組成 $x_i$ が与えられたとき、気相組成の合計が1になる条件から求めます。

$$\sum_i K_i(T)\,x_i = 1$$

露点は、蒸気を冷やしていって最初の液滴ができる温度です。気相組成 $y_i$ が与えられたとき、液相組成の合計が1になる条件から求めます。

$$\sum_i \frac{y_i}{K_i(T)} = 1$$

どちらも温度についての1変数の方程式なので、温度を仮定して左辺を計算し、1になるまで調整すれば解けます。左辺は温度とともに単調に変わるので、二分法で確実に求まります。

1.4 フラッシュ計算

原料（組成 $z_i$）を、ある温度・圧力の容器に入れて気液平衡にしたとき、どれだけ蒸発し、気相・液相の組成がどうなるかを求める計算です。蒸発率 $\psi = V/F$ を使うと、成分ごとの物質収支と平衡関係から

$$x_i = \frac{z_i}{1 + \psi\,(K_i - 1)}, \qquad y_i = K_i\,x_i$$

となります。$\sum y_i - \sum x_i = 0$ の条件から、次のラシュフォード・ライスの式が得られます。

$$\sum_i \frac{z_i\,(K_i - 1)}{1 + \psi\,(K_i - 1)} = 0$$

左辺は $\psi$ について単調に減少するので、$0 < \psi < 1$ の範囲で二分法などで確実に解けます。温度が沸点より低ければ全部液、露点より高ければ全部蒸気で、フラッシュ計算に意味があるのは沸点と露点の間だけです。

1.5 例題1：ベンゼン－トルエン－p-キシレン

ベンゼン 40 mol%、トルエン 35 mol%、p-キシレン 25 mol% の混合物について、1気圧（760 mmHg）での沸点、露点、110 °C でのフラッシュの結果を求めてください。ラウールの法則が成り立つとし、蒸気圧は次のアントワン式（mmHg、°C）で計算します。

成分ABC標準沸点（計算値）
ベンゼン6.905651211.033220.79080.10 °C
トルエン6.954641344.800219.482110.63 °C
p-キシレン6.990521453.430215.310138.35 °C

解答

沸点：$\sum K_i x_i = 1$ を解くと 98.4 °C。そのとき最初に出る蒸気の組成は、ベンゼン 0.681、トルエン 0.244、p-キシレン 0.075 です。

露点：$\sum y_i / K_i = 1$ を解くと 113.2 °C。最初にできる液滴の組成は、ベンゼン 0.160、トルエン 0.325、p-キシレン 0.515 です。

110 °C でのフラッシュ：各成分の K値は、ベンゼン 2.311、トルエン 0.982、p-キシレン 0.438 です。ラシュフォード・ライスの式を解くと、蒸発率 $\psi$ = 0.788 です。

トルエン0.9820.3550.349

各成分について $\psi y_i + (1 - \psi) x_i$ を計算すると原料組成に戻り、液組成と蒸気組成の合計もそれぞれ1になることで、計算が正しいことを確かめられます。

トルエンの K値がほぼ1であることに注目してください。110 °C はトルエンの沸点に近いので、トルエンは気相と液相にほぼ均等に分かれます。

1.6 非理想系と活量係数

水とアルコール、アセトンとクロロホルムのように、分子の性質が大きく違う成分の混合物では、ラウールの法則から大きくずれます。このずれを活量係数 $\gamma_i$ で補正します。

$$y_i\,P = \gamma_i\,x_i\,p_i^{\text{sat}}(T)$$
  • $\gamma_i > 1$（正のずれ）：同じ種類の分子どうしが引き合う力が強く、混ざると逃げ出しやすくなる。沸点が下がる方向
  • $\gamma_i < 1$（負のずれ）：異なる分子どうしが強く引き合う。沸点が上がる方向

活量係数は組成と温度によって変わり、活量係数モデルで表します。代表的なものは次のとおりです。

モデル特徴
マーギュレス式最も簡単。2成分系の説明や、ずれの小さい系に
ファン・ラール式簡単で、2成分系のデータの整理に広く使われてきた
ウィルソン式多成分系に拡張しやすく精度もよい。ただし液液分離（2液相）は表せない
NRTL 式液液分離も表せる。パラメータが3つ（2成分系あたり）
UNIQUAC 式・UNIFAC 法分子の大きさや官能基から計算。UNIFAC はデータがない系の推算に使う

どのモデルも、パラメータは実測の気液平衡データから決めます。パラメータの値はモデルの形と組み合わせが決まっていて、別のモデルや別の資料の値を混ぜて使うことはできません。データ集やプロセスシミュレーターの値を使うときは、出典と適用範囲（温度・圧力）を必ず確認してください。

1.7 例題2：活量係数が共沸を生むしくみ

活量係数の効果を見るため、説明用の仮想の2成分系を考えます。成分1の蒸気圧はベンゼンの 0.7 倍、成分2の蒸気圧はトルエンと同じとし、2パラメータのマーギュレス式

$$\ln \gamma_1 = x_2^2\left[A_{12} + 2(A_{21} - A_{12})\,x_1\right], \qquad \ln \gamma_2 = x_1^2\left[A_{21} + 2(A_{12} - A_{21})\,x_2\right]$$

で $A_{12}$ = 1.6、$A_{21}$ = 0.9（説明用の値）とします。1気圧での沸点と気相組成を、理想溶液の場合と比べてください。

正のずれによって、どの組成でも沸点が理想溶液より大きく下がっています。さらに、$x_1$ = 0.7 付近で気相組成と液相組成がほぼ等しくなっています。$y_1 = x_1$ となる点を探すと、$x_1$ = 0.684、89.9 °C で共沸します。ここで沸点が最も低くなる（最低共沸点）ため、普通の蒸留ではこの組成を越えて成分1を濃縮することはできません。

理想溶液なら沸点 80 °C と 110 °C の間で素直に変化するはずの系でも、活量係数によって共沸が生まれることがわかります。共沸があるかどうかは、蒸留の設計の前に必ず確かめる必要があります。

1.8 検算について

本章の数値は、検算用プログラム（check_ch01.py）で計算しています。沸点・露点・フラッシュはそれぞれ二分法で解き、フラッシュの結果は各成分の物質収支と組成の合計で確認しました。アントワン定数から計算した3成分の標準沸点（80.10 °C、110.63 °C、138.35 °C）は、よく知られた実測値とよく一致します。
