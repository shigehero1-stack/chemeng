8.1 この章で学ぶこと

このサイトの反応工学の記事では、反応が1つだけ（A → 生成物）の場合を扱い、「同じ反応率なら管型反応器（PFR）のほうが小さくて済む」ことを見ました。しかし工業的な反応では、目的の反応と同時に、望まない副反応が起こることがほとんどです。

このような複合反応では、反応器の大きさ以上に「原料のうちどれだけが目的の製品になるか」が重要になります。原料費は多くの化学プロセスで製造コストの大きな部分を占めるため、目的物の収率が数%上がるだけで、採算が大きく変わることもあります。

本章では、複合反応の2つの基本形である並列反応と逐次反応について、反応器の形式と運転条件が目的物の量にどう影響するかを、例題と数値計算で確かめます。

8.2 収率と選択率

複合反応の成績は、次の量で表します。定義は文献によって少しずつ違うので、資料を読むときは必ず定義を確認してください。本章では、原料 A から目的物 R と副生物 S ができる場合について、次のように定義します（量論係数はすべて1とします）。

名前定義意味
反応率 $X_A$$(C_{A0} - C_A) / C_{A0}$原料のうち反応した割合
収率 $Y_R$$C_R / C_{A0}$仕込んだ原料のうち目的物になった割合
選択率 $S_R$$C_R / (C_{A0} - C_A)$反応した原料のうち目的物になった割合
瞬間選択率 $\varphi$$r_R / (-r_A)$ある瞬間に反応している原料のうち目的物になる割合

収率 = 反応率 × 選択率 の関係があります。反応率を上げても選択率が下がれば、収率は伸びません。

8.3 並列反応

1つの原料が、同時に2つの経路で反応する場合です。

$$\text{A} \xrightarrow{k_1} \text{R}\ (\text{目的物}), \qquad \text{A} \xrightarrow{k_2} \text{S}\ (\text{副生物})$$

それぞれの反応速度を $r_R = k_1 C_A^{a_1}$、$r_S = k_2 C_A^{a_2}$ とすると、瞬間選択率は

$$\varphi = \frac{k_1 C_A^{a_1}}{k_1 C_A^{a_1} + k_2 C_A^{a_2}} = \frac{1}{1 + (k_2/k_1)\,C_A^{\,a_2 - a_1}}$$

となります。ここから、濃度の影響について次の規則が得られます。

  • 目的反応の次数が高い（$a_1 > a_2$）：原料の濃度を高く保つほど有利。管型反応器や回分反応器が向き、連続槽型反応器（CSTR）は不利
  • 目的反応の次数が低い（$a_1 < a_2$）：原料の濃度を低く保つほど有利。CSTR や、原料を少しずつ加える半回分操作が向く
  • 次数が同じ：濃度は選択率に影響せず、$k_1/k_2$ だけで決まる。温度や触媒で $k_1/k_2$ を変えるしかない

温度の影響は、2つの反応の活性化エネルギーで決まります。目的反応の活性化エネルギーが大きければ高温が、小さければ低温が選択率に有利です。

反応器ごとの目的物の量

  • CSTR：槽内の濃度は出口の濃度 $C_{A}$ で一定なので、$C_R = \varphi(C_A)\,(C_{A0} - C_A)$
  • PFR・回分：濃度が入口から出口へ変化するので、瞬間選択率を積分して $C_R = \displaystyle\int_{C_A}^{C_{A0}} \varphi\,dC_A$

例題1：並列反応での反応器の選択

原料 A（初濃度 1.0 mol/L）から、目的物 R が2次反応（$k_1$ = 0.5 L/(mol·min)）で、副生物 S が1次反応（$k_2$ = 0.1 1/min）でできます。反応率 90% で運転するとき、CSTR と PFR それぞれの R の収率を求めてください。

解答

出口濃度は $C_A = 0.10$ mol/L です。瞬間選択率は

$$\varphi = \frac{0.5\,C_A^2}{0.5\,C_A^2 + 0.1\,C_A} = \frac{0.5\,C_A}{0.5\,C_A + 0.1}$$

CSTR：$\varphi(0.10) = 0.05 / 0.15 = 0.333$ なので、$C_R = 0.333 \times 0.90 = 0.30$ mol/L。収率 30%

PFR：

$$C_R = \int_{0.10}^{1.0} \frac{0.5\,C_A}{0.5\,C_A + 0.1}\,dC_A = (1.0 - 0.10) - \frac{0.1}{0.5}\ln\frac{0.5 \times 1.0 + 0.1}{0.5 \times 0.10 + 0.1} \approx 0.623\ \text{mol/L}$$

収率は約 62% で、CSTR の2倍以上です。さらに必要な空間時間も、CSTR の 60 分に対して PFR は約 9.2 分と、大きく違います。目的反応の次数が高いので、濃度が高い状態で反応させられる PFR が有利になる典型例です。

8.4 逐次反応

原料からできた目的物が、さらに反応して別の物質になってしまう場合です。

$$\text{A} \xrightarrow{k_1} \text{B}\ (\text{目的物}) \xrightarrow{k_2} \text{C}\ (\text{副生物})$$

部分酸化（原料を酸化して中間生成物を得たいが、酸化が進みすぎると二酸化炭素になってしまう）や、塩素化、重合などがこの形です。

逐次反応では、反応時間が短すぎると原料が残り、長すぎると目的物が分解してしまうため、目的物の濃度が最大になる最適な反応時間が存在します。

回分反応器・PFR の場合

両方の反応が1次で、最初に A だけがある場合、濃度の変化は次の式で表されます（$k_1 \ne k_2$）。

$$\frac{C_A}{C_{A0}} = e^{-k_1 t}, \qquad \frac{C_B}{C_{A0}} = \frac{k_1}{k_2 - k_1}\left(e^{-k_1 t} - e^{-k_2 t}\right)$$

$C_B$ が最大になる時間と、そのときの濃度は

$$t_{\text{opt}} = \frac{\ln (k_2/k_1)}{k_2 - k_1}, \qquad \frac{C_{B,\max}}{C_{A0}} = \left(\frac{k_1}{k_2}\right)^{k_2/(k_2 - k_1)}$$

です。PFR では、$t$ を空間時間 $\tau$ に読みかえます。

CSTR の場合

$$\frac{C_B}{C_{A0}} = \frac{k_1 \tau}{(1 + k_1\tau)(1 + k_2\tau)}$$

これを最大にする空間時間と、そのときの濃度は

$$\tau_{\text{opt}} = \frac{1}{\sqrt{k_1 k_2}}, \qquad \frac{C_{B,\max}}{C_{A0}} = \frac{1}{\left(1 + \sqrt{k_2/k_1}\right)^2}$$

です。

例題2：逐次反応の最適な反応時間

$k_1$ = 0.2 1/min、$k_2$ = 0.1 1/min の逐次反応で、目的物 B を最も多く得るための条件と、そのときの収率を、PFR と CSTR で比べてください。

解答

PFR：$t_{\text{opt}} = \dfrac{\ln(0.1/0.2)}{0.1 - 0.2} \approx 6.93$ min、$\dfrac{C_{B,\max}}{C_{A0}} = 2^{-1} = 0.50$

このときの反応率は 75% で、原料の 4 分の 1 が未反応のまま残っています。

CSTR：$\tau_{\text{opt}} = 1/\sqrt{0.02} \approx 7.07$ min、$\dfrac{C_{B,\max}}{C_{A0}} = \dfrac{1}{(1 + \sqrt{0.5})^2} \approx 0.343$

PFR のほうが最大収率が約 1.5 倍高くなります。CSTR では、入ってきたばかりの原料と、長く滞在して分解が進んだ目的物が混ざってしまうため、逐次反応には不利です。

PFR で反応時間を変えたときの組成は次のとおりです（$C_{A0}$ = 1）。

反応時間が短いほど選択率は高く、長いほど反応率は高くなります。反応率を上げることが、必ずしも良い結果につながらないことがわかります。

実際の運転での考え方

表のように反応時間 3 分で止めると、収率は 38% に下がりますが、選択率は 85% になります。未反応の A を分離して反応器に戻す（リサイクルする）プロセスでは、1回あたりの反応率を低めにして選択率を高く保つほうが、全体の収率が高くなることがあります。どの運転点がよいかは、分離とリサイクルにかかる費用を含めたプロセス全体で判断します（第14章で扱います）。

8.5 まとめ：反応器の選び方の目安

反応の形目的物に有利な条件向いている反応器・操作
並列、目的反応の次数が高い原料濃度を高くPFR、回分
並列、目的反応の次数が低い原料濃度を低くCSTR、原料を少しずつ加える半回分
逐次（目的物が中間体）滞留時間をそろえ、最適な時間で止めるPFR、回分。CSTR は不利

8.6 検算について

本章の例題は、検算用プログラム（check_ch08.py）で確認しています。逐次反応の例題は、微分方程式を4次のルンゲ・クッタ法で数値積分した結果（$t$ = 6.93 min で $C_A$ = 0.2500、$C_B$ = 0.5000、$C_C$ = 0.2500）と解析解が一致すること、CSTR の最適空間時間は空間時間を少しずつ変えて探した最大値と一致することを確かめています。並列反応の PFR の収率は、解析解（0.6227）と数値積分（0.6227）が一致しています。
