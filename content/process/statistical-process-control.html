ばらつきを「ふだん」と「異常」に分ける

同じ条件で運転していても、製品の濃度や純度は毎回少しずつ違います。原料のわずかな違い、測定の誤差、温度の小さな揺れなど、数え切れない原因が少しずつ効いているからです。このような避けられないばらつきを偶然原因によるばらつきといいます。

一方、触媒の劣化、計器の故障、原料ロットの切り替えなど、特定できる原因で工程の状態そのものが変わることもあります。これを異常原因といいます。品質管理の第一歩は、目の前のばらつきがどちらなのかを見分け、異常原因だけを素早く見つけて取り除くことです。そのための道具が管理図です。

管理図は、フィードバック制御が数秒〜数分の変化を自動で打ち消すのに対し、日単位の分析値の変化を人が見て判断するための道具だといえます。

X̄-R 管理図の作り方

連続運転のプラントでよく使われるのが X̄-R 管理図です。次の手順で作ります。

  1. 一定の間隔（たとえば1日1回）で、製品を $n$ 個（ふつう4〜5個）測り、これを1つの群とする
  2. 群ごとに平均 $\bar{X}$ と範囲 $R$（最大値 − 最小値）を計算する
  3. 20〜25群のデータから、群の平均の平均 $\bar{\bar{X}}$ と、範囲の平均 $\bar{R}$ を求める
  4. 次の式で中心線と管理限界を決め、グラフに描く
$$\bar{X}\ \text{管理図}: \quad \mathrm{UCL} = \bar{\bar{X}} + A_2\bar{R}, \qquad \mathrm{LCL} = \bar{\bar{X}} - A_2\bar{R}$$
$$R\ \text{管理図}: \quad \mathrm{UCL} = D_4\bar{R}, \qquad \mathrm{LCL} = D_3\bar{R}$$

$A_2$、$D_3$、$D_4$ は群の大きさ $n$ で決まる係数で、$n$ = 5 なら $A_2$ = 0.577、$D_3$ = 0（下限なし）、$D_4$ = 2.114 です。これらは、管理限界が平均から標準偏差の3倍（3σ）離れた位置になるように決められています。工程が偶然原因だけで動いていれば、点が管理限界の外に出る確率は 0.3% ほどしかありません。

工程の標準偏差は、範囲の平均から $\hat{\sigma} = \bar{R}/d_2$ で推定できます（$n$ = 5 なら $d_2$ = 2.326）。

例題：製品濃度の管理図と工程能力

製品の濃度の規格は 50.0 ± 1.0 wt%（49.0〜51.0 wt%）です。1日1回、5個の試料を分析し、20日分のデータ（当サイトで作成した例）から、$\bar{\bar{X}}$ = 50.20 wt%、$\bar{R}$ = 0.70 wt% が得られました。

(1) $\bar{X}$ 管理図と $R$ 管理図の管理限界を求めてください。

(2) 工程の標準偏差を推定し、工程能力指数 $C_p$ と $C_{pk}$ を求めてください。

(1) $\bar{X}$ 管理図：$\mathrm{UCL} = 50.20 + 0.577 \times 0.70 = 50.61$、$\mathrm{LCL} = 50.20 - 0.40 = 49.80$ wt%

$R$ 管理図：$\mathrm{UCL} = 2.114 \times 0.70 = 1.48$ wt%、LCL はなし

20日分の点はすべて管理限界の内側にあり（図1の左側）、この期間の工程は安定していた（管理状態にあった）と判断できます。

(2) $\hat{\sigma} = 0.70 / 2.326 = 0.301$ wt%

$C_p = \dfrac{51.0 - 49.0}{6 \times 0.301} = 1.11$、$C_{pk} = \dfrac{\min(51.0 - 50.20,\ 50.20 - 49.0)}{3 \times 0.301} = \dfrac{0.80}{0.903} = 0.88$

異常の見つけ方

管理限界を決めたら、その後のデータを同じ図に描き続けます。図1の右側（21日目以降）では、23日目の点が UCL を超えました。これは「工程に何か変化が起きた」という合図です。24日目はいったん内側に戻っていますが、25日目と26日目も外に出ており、濃度が高い側にずれたことがはっきりしました。ここで原因（たとえば反応温度の計器のずれ、原料の切り替え）を調べて取り除きます。

管理限界の外に出なくても、次のような点の並び方は異常の兆しとして扱います。

  • 中心線の片側に、点が連続して7〜9点以上並ぶ（平均が少しずれた）
  • 点が連続して6点以上、上がり続ける、または下がり続ける（触媒の劣化など、ゆっくり進む変化）
  • 点が周期的に上下する（昼と夜、交代勤務の班による違いなど）

大切なのは、管理限界と規格は別のものだということです。管理限界は工程のふだんのばらつきから決まり、規格はお客さまの要求から決まります。規格の内側でも、管理限界の外に出たら原因を調べます。逆に、管理限界の内側にあるのに、規格に近いからといって運転条件をいじると、かえってばらつきを大きくしてしまいます。

工程能力指数の読み方

工程能力指数は、規格の幅と工程のばらつきを比べた数字です。

$$C_p = \frac{\mathrm{USL} - \mathrm{LSL}}{6\sigma}, \qquad C_{pk} = \frac{\min(\mathrm{USL} - \mu,\ \mu - \mathrm{LSL})}{3\sigma}$$

USL と LSL は規格の上限と下限、$\mu$ は工程の平均です。$C_p$ はばらつきの大きさだけを、$C_{pk}$ は平均のかたよりも含めて評価します。

一般に、$C_{pk}$ が 1.33 以上なら工程能力は十分、1.00〜1.33 なら管理に注意が必要、1.00 未満なら不足とされます。例題の工程は、$C_p$ = 1.11 に対して $C_{pk}$ = 0.88 と、平均が上限側に 0.20 wt% かたよっているために能力が不足しています。

正規分布を仮定すると、規格の上限を超える割合は、上限が平均から $0.80/0.301 = 2.65\sigma$ 離れているので約 0.4% です。平均を規格の中心の 50.0 wt% に合わせれば、$C_{pk}$ は $C_p$ と同じ 1.11 になり、規格外は両側を合わせて約 0.09% まで減ります。さらに $C_{pk}$ を 1.33 にするには、標準偏差を 0.25 wt% まで小さくする必要があり、分析の誤差や原料のばらつきの低減に取り組むことになります。

使うときの注意

  • 工程能力指数は、工程が管理状態にある（管理図で異常がない）ときのデータで計算します。異常を含むデータで計算しても、意味のある数字になりません
  • 連続プラントの分析値は、前の日の値と似る（自己相関がある）ことが多く、そのまま X̄-R 管理図を使うと異常の判定が多すぎることがあります。1日1点の値を使う個々の値の管理図（X-Rs 管理図）や、移動平均を使う方法も検討します
  • 分析そのもののばらつきが大きいと、工程のばらつきが実際より大きく見えます。同じ試料をくり返し測って、分析の精度を確かめておきましょう。データのあてはめ方の基本は最小二乗法の記事も参考になります
