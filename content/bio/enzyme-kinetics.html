酵素は生体の触媒

酵素は、生物がつくるタンパク質の触媒です。常温・常圧の穏やかな条件で、特定の物質（基質）だけを選んで反応させる性質（基質特異性）をもっています。洗剤に入っているプロテアーゼ、でんぷんを糖に分解するアミラーゼ、果糖ぶどう糖液糖をつくるグルコースイソメラーゼなど、工業的にも広く使われています。

酵素反応の速さは、ふつうの化学反応とは違う形の式で表されます。それがミカエリス・メンテン式です。

ミカエリス・メンテン式

酵素 E は、まず基質 S と結合して複合体 ES をつくり、ES が生成物 P を放出して元の酵素に戻ります。

$$\mathrm{E} + \mathrm{S} \;\rightleftharpoons\; \mathrm{ES} \;\longrightarrow\; \mathrm{E} + \mathrm{P}$$

複合体 ES の濃度がすぐに一定になる（定常状態近似）と考え、酵素の全濃度が一定であることを使うと、反応速度 $v$ は次のようになります。

$$v = \frac{V_{max}\,S}{K_m + S}$$

$V_{max}$ は最大反応速度で、すべての酵素が基質と結合しているときの速さです。酵素の量に比例します。$K_m$ はミカエリス定数で、反応速度が $V_{max}$ の半分になる基質濃度を表し、小さいほど低い濃度の基質ともよく結合することを意味します。

  • $S \ll K_m$ のとき：$v \approx (V_{max}/K_m)\,S$。基質濃度に比例する1次反応
  • $S \gg K_m$ のとき：$v \approx V_{max}$。基質濃度によらない0次反応（酵素が手いっぱいの状態）

この形は、微生物の増殖を表すモノー式や、固体触媒の表面反応を表すラングミュア型の速度式と同じです。

パラメータの求め方：ラインウィーバー・バークプロット

基質濃度を変えて反応の初速度を測り、$V_{max}$ と $K_m$ を求めます。ミカエリス・メンテン式の両辺の逆数をとると、直線の式になります。

$$\frac{1}{v} = \frac{K_m}{V_{max}}\cdot\frac{1}{S} + \frac{1}{V_{max}}$$

$1/v$ を $1/S$ に対してプロット（ラインウィーバー・バークプロット）すると、切片が $1/V_{max}$、傾きが $K_m/V_{max}$ の直線になります。

$1/S$ と $1/v$ を計算して最小二乗法で直線をあてはめると、切片 0.508、傾き 2.45 が得られます（図2）。

$V_{max} = 1/0.508 = 1.97$ mmol/(L·min)、$K_m = 2.45 \times 1.97 = 4.81$ mmol/L

ラインウィーバー・バークプロットは直感的でわかりやすい反面、基質濃度の低い点（$1/S$ が大きい点）の誤差が逆数で拡大され、直線の傾きに強く効くという欠点があります。精度が必要なときは、ミカエリス・メンテン式を直接データにあてはめる非線形の最小二乗法を使います。

阻害剤があると

酵素の働きを妨げる物質を阻害剤といいます。基質とよく似た形をしていて、酵素の同じ場所を奪い合う競争阻害では、阻害剤の濃度 $I$ と阻害定数 $K_i$ を使って

$$v = \frac{V_{max}\,S}{K_m\left(1 + \dfrac{I}{K_i}\right) + S}$$

となります。$V_{max}$ は変わりませんが、見かけの $K_m$ が $(1 + I/K_i)$ 倍に大きくなります。基質濃度を十分高くすれば、阻害の影響は小さくなります。図1は、$K_i$ = 5 mmol/L の阻害剤が 10 mmol/L あると、見かけの $K_m$ が 3 倍の 15 mmol/L になる様子です。反応でできた生成物そのものが阻害剤として働く生成物阻害もよく見られます。

回分反応器での反応時間

回分反応器で基質濃度が $S_0$ から $S$ まで下がる時間は、ミカエリス・メンテン式を回分反応器の式 $-dS/dt = v$ で積分して求められます。

$$V_{max}\,t = K_m \ln\frac{S_0}{S} + (S_0 - S)$$
例題2：転化率 95% までの時間

$V_{max}$ = 2.0 mmol/(L·min)、$K_m$ = 5.0 mmol/L の酵素で、基質濃度 50 mmol/L の液を転化率 95% まで反応させる時間を求めてください。また、$K_i$ = 5.0 mmol/L の競争阻害剤が 10 mmol/L 含まれている場合の時間も求めてください。

$S = 50 \times 0.05 = 2.5$ mmol/L、$\ln(50/2.5) = \ln 20 = 3.00$

阻害剤なし：$t = \dfrac{5.0 \times 3.00 + (50 - 2.5)}{2.0} = \dfrac{15.0 + 47.5}{2.0} = 31$ 分

阻害剤あり：見かけの $K_m = 5.0 \times (1 + 10/5.0) = 15$ mmol/L なので

$t = \dfrac{15 \times 3.00 + 47.5}{2.0} = \dfrac{45.0 + 47.5}{2.0} = 46$ 分

阻害剤によって、反応時間は 1.5 倍に延びます。基質濃度の高い前半（0次反応に近い）ではあまり遅くならず、基質が減った後半で大きく遅くなります。

工業的に使うときの工夫

  • 固定化酵素：酵素を樹脂や担体の粒に結合させると、反応後に分離して何度も使え、充填層で連続的に反応させることもできます。ただし、粒の中への基質の拡散が遅いと、触媒有効係数と同じ考え方で見かけの速度が下がります
  • 温度と pH：酵素は温度を上げると反応が速くなりますが、高すぎるとタンパク質の構造が壊れて失活します。失活も1次反応で表せることが多く、反応の速さと寿命の兼ね合いで運転温度を決めます
  • 酵素の値段：酵素は高価なので、反応時間を短くするために酵素を増やすか、反応器を大きくするかは、経済性の比較で決めます
