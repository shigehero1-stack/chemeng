安全弁の吹出し面積の計算

容器や配管を過圧から守る安全弁のしくみ、設定圧力と過圧の考え方、どの異常で何 kg/h を逃がすかという所要吹出し量の決め方、気体の臨界流れの式（API 520 の形）による必要な吹出し面積の計算とオリフィスの選定を、窒素の減圧弁故障の例題で解説します。

安全弁は最後の守り

圧力容器や配管は、設計圧力を超える圧力がかかると破裂するおそれがあります。圧力の異常は、ふつうは制御系や警報、運転員の操作で防ぎますが、それらがすべて働かなかったときに、自動的に圧力を逃がして設備を守るのが安全弁です。プロセス安全の考え方では、安全弁は事故を防ぐ最後の防護層の一つに位置づけられます。

もっとも広く使われるのは、図1のようなばね式安全弁です。ふだんは、ばねの力で弁体が弁座に押しつけられて閉じています。容器の圧力が上がって、弁体を押し上げる力がばねの力を超えると弁が開き、ガスや液体を外に逃がします。圧力が下がると、ばねの力で再び閉じます。

設定圧力と過圧

安全弁が開き始める圧力を設定圧力（吹出し圧力）といい、ふつうは容器の設計圧力（最高使用圧力）以下に設定します。安全弁は、設定圧力ですぐに全開になるわけではなく、圧力がもう少し上がってから必要な量を流せる開度になります。この上乗せ分を過圧（オーバープレッシャー）といい、一般的な運転の異常に対しては設定圧力の 10%、火災で容器が加熱される場合は 21% まで認める考え方が広く使われています。

安全弁の大きさは、設定圧力に過圧を加えた圧力（吹出し時の圧力）で、必要な量を流しきれるように決めます。

所要吹出し量を決める

安全弁の計算で最も大切で、最も難しいのは、「どんな異常のときに、何 kg/h を逃がす必要があるか」という所要吹出し量を決めることです。考えられる異常をすべて洗い出し、それぞれで流入する量を計算して、最も大きいものを使います。代表的な異常には次のようなものがあります。

  • 出口の閉止：出口の弁が誤って閉じたのに、ポンプや圧縮機が送り続ける
  • 減圧弁・調節弁の故障：高圧の供給源から低圧の設備へ減圧する弁が全開で固着し、高圧のガスが流れ込む
  • 冷却の喪失：蒸留塔のコンデンサーの冷却水が止まり、発生した蒸気を凝縮できなくなる
  • 外部火災：容器が炎にあぶられ、中の液体が蒸発する
  • 反応の暴走：熱暴走でガスが急に発生する。気液二相の流れになることが多く、特別な計算が必要

異常の洗い出しには、HAZOPの結果が役立ちます。

気体の吹出し面積の式

気体が安全弁のノズルを通るとき、出口側の圧力（背圧）が十分低いと、のど部の流速が音速に達し、それ以上背圧を下げても流量が増えなくなります。これを臨界流れ（チョーク）といいます。臨界流れになるのは、背圧と入口の圧力の比（絶対圧）が、次の臨界圧力比より小さいときです。

$$\frac{P_2}{P_1} < \left(\frac{2}{k+1}\right)^{k/(k-1)}$$

$k$ は比熱比で、窒素や空気（$k$ = 1.40）では 0.528 になります。大気に放出する安全弁の多くは臨界流れで、流量は入口の圧力だけで決まります（図2）。

臨界流れで必要な吹出し面積 $A$ [mm²] は、米国石油協会の規格 API 520 で使われる次の式で求められます。

$$A = \frac{W}{C\,K_d\,P_1\,K_b\,K_c}\sqrt{\frac{T\,Z}{M}}, \qquad C = 0.03948\sqrt{k\left(\frac{2}{k+1}\right)^{(k+1)/(k-1)}}$$

$W$ は所要吹出し量 [kg/h]、$P_1$ は吹出し時の入口の圧力 [kPa（絶対圧）]、$T$ は入口の温度 [K]、$Z$ は圧縮係数、$M$ はモル質量 [g/mol] です。$K_d$ は流出係数（予備計算では 0.975）、$K_b$ は背圧による補正、$K_c$ は破裂板を組み合わせるときの補正で、どちらも該当しなければ 1 とします。この式は、音速で流れるノズルの理論式に、単位の換算をまとめて係数 $C$ に入れたものです。

例題：窒素の減圧弁が全開で固着した場合

窒素の配管から減圧弁を通して、設計圧力 1.0 MPaG の受槽に窒素を供給しています。減圧弁が全開で固着すると、窒素が最大 1500 kg/h 流れ込みます。受槽の安全弁の設定圧力を 1.0 MPaG、過圧を 10% として、必要な吹出し面積を求め、オリフィスを選んでください。窒素の温度は 40 °C、比熱比は 1.40、圧縮係数は 1.00 とし、安全弁は大気に放出します。

吹出し時の入口の圧力：$P_1 = 1.0 \times 1.10 + 0.101 = 1.201$ MPa ＝ 1201 kPa（絶対圧）

臨界流れの確認：$P_2 / P_1 = 101 / 1201 = 0.084 < 0.528$ なので臨界流れ

係数：$C = 0.03948 \times \sqrt{1.40 \times (2/2.40)^{6}} = 0.03948 \times \sqrt{0.4689} = 0.02703$

吹出し面積：$A = \dfrac{1500}{0.02703 \times 0.975 \times 1201 \times 1 \times 1} \times \sqrt{\dfrac{313.15 \times 1.00}{28.01}} = 47.4 \times 3.344 = 158$ mm²

API 526 で標準化されたオリフィスの大きさのうち、158 mm² 以上で最も小さいのは F（198 mm²）です。F を選ぶと、同じ条件で流せる量は $1500 \times 198 / 158 = 1880$ kg/h になり、所要量に対して約 25% の余裕があります。

液体の場合

液体を逃がす安全弁では臨界流れは起きず、流量は弁の前後の圧力差で決まります。ベルヌーイの式から、ノズルを通る流速は $\sqrt{2\Delta P/\rho}$ なので、必要な面積は次のようになります（$Q$ [L/min]、$\Delta P$ [kPa]、$G$ は水に対する比重）。

$$A = \frac{11.78\,Q}{K_d\,K_w\,K_c\,K_v}\sqrt{\frac{G}{\Delta P}}$$

$K_w$ は背圧、$K_v$ は粘度による補正です。液体で満たされた配管が日射などで温められて膨張する場合（熱膨張）は、流量はわずかなので小さな安全弁で足ります。

破裂板との使い分け

過圧を逃がす装置には、安全弁のほかに破裂板（ラプチャーディスク）があります。決められた圧力で薄い金属の板が破れて圧力を逃がすもので、次のような特徴があります。

  • 開くのが速い：反応の暴走や粉じん爆発のように、圧力がミリ秒〜秒の単位で上がる場合に向いている
  • 漏れがない：毒性の強いガスや、高価な物質を扱う容器に向いている
  • 一度破れると閉じない：圧力が下がっても中身が出続けるので、運転を止めて板を交換する必要がある
  • 腐食や固着から安全弁を守る：腐食性の液体やポリマーが固まりやすい容器では、安全弁の入口側に破裂板を置き、安全弁を接液させない組み合わせが使われる。このとき吹出し面積の式の $K_c$ は 0.9 程度を使う

設置で気をつけること

  • 入口配管の圧力損失：安全弁までの配管で圧力が大きく下がると、弁が開閉をくり返す（チャタリング）原因になります。入口の圧力損失は設定圧力の 3% 以内に抑えるのが一般的な目安です
  • 背圧：放出先の配管が長いと、吹き出した流れで背圧が上がります。ふつうのばね式安全弁では、吹出し時の背圧を設定圧力の 10% 程度までに抑えます。それを超える場合は、背圧の影響を受けにくいベローズ式やパイロット式を使います
  • 放出先：可燃性や毒性のガスは、そのまま大気に出さず、フレアスタックや除害設備に送ります
  • 法規と点検：日本では、高圧ガス保安法、労働安全衛生法（ボイラー・圧力容器）などで安全弁の設置と計算方法、定期的な検査が定められています。実際の設計では、設備に適用される法規と規格の式を使い、メーカーの認定された能力の値で確認します

容器そのものの強さの計算は、圧力容器の肉厚計算の記事で扱います。
