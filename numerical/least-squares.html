最小二乗法とパラメータ推定

実験データから式のパラメータを決める最小二乗法の考え方と計算式を、速度定数のデータから活性化エネルギーを求める例題と Python のプログラムで解説します。

パラメータ推定とは

化学工学では、反応速度式の速度定数や活性化エネルギー、物性の相関式の係数など、式に含まれる定数（パラメータ）を実験データから決める場面がよくあります。これをパラメータ推定といい、その最も基本的な方法が最小二乗法です。

最小二乗法の考え方

測定データ $(x_i, y_i)$ に直線 $y = a + bx$ を当てはめるとき、各点での「測定値と直線の差（残差）」の2乗の合計

$$S = \sum_{i=1}^{n} \left( y_i - a - b x_i \right)^2$$

が最も小さくなるように $a$ と $b$ を決めます。2乗するのは、プラスとマイナスの誤差が打ち消し合わないようにするためです。$S$ を $a$、$b$ で微分して0とおくと、次の式が得られます。

$$b = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}, \qquad a = \bar{y} - b\,\bar{x}$$

$\bar{x}$、$\bar{y}$ はそれぞれの平均値です。

当てはまりの良さ：決定係数

直線がデータにどれだけよく合っているかは、決定係数 $R^2$ で表します。

$$R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$

$\hat{y}_i$ は直線による計算値です。1に近いほどよく当てはまっています。ただし、$R^2$ が大きくても、式の形そのものが正しいとは限りません。残差を $x$ に対してプロットし、系統的な傾向（曲がりなど）がないかも確かめましょう。

曲線の式は変形して直線にする

アレニウスの式 $k = A \exp(-E/RT)$ のように直線でない式も、両辺の対数をとると

$$\ln k = \ln A - \frac{E}{R}\cdot\frac{1}{T}$$

となり、$x = 1/T$、$y = \ln k$ とすれば直線の当てはめで扱えます。傾き $b$ から $E = -bR$、切片 $a$ から $A = e^a$ が求まります。

例題：速度定数のデータから活性化エネルギーを求める

ある反応の速度定数を、5つの温度で測定しました。

温度 [K]300310320330340
速度定数 [1/s]3.15 × 10⁻⁴6.92 × 10⁻⁴1.46 × 10⁻³2.96 × 10⁻³5.77 × 10⁻³

活性化エネルギーと頻度因子を求めてください。

$1/T$ と $\ln k$ を計算して最小二乗法で直線を当てはめます。次の Python のプログラムは、標準の機能だけで動きます。

import math

T = [300, 310, 320, 330, 340]                 # 温度 [K]
k = [3.15e-4, 6.92e-4, 1.46e-3, 2.96e-3, 5.77e-3]   # 速度定数 [1/s]

x = [1 / t for t in T]                        # 横軸 1/T
y = [math.log(v) for v in k]                  # 縦軸 ln k
n = len(x)
xm, ym = sum(x) / n, sum(y) / n
b = sum((xi - xm) * (yi - ym) for xi, yi in zip(x, y)) / sum((xi - xm) ** 2 for xi in x)
a = ym - b * xm

R = 8.314
E = -b * R                                    # 傾き = -E/R
A = math.exp(a)                               # 切片 = ln A
r2 = 1 - sum((yi - (a + b * xi)) ** 2 for xi, yi in zip(x, y)) / sum((yi - ym) ** 2 for yi in y)
print(f"E = {E/1000:.1f} kJ/mol, A = {A:.2e} 1/s, R^2 = {r2:.5f}")

実行結果：

E = 61.7 kJ/mol, A = 1.71e+07 1/s, R^2 = 0.99998

活性化エネルギーは約 62 kJ/mol です。決定係数が 1 にとても近く、アレニウスの式でよく表せていることがわかります。

使うときの注意

  • 変形すると誤差の重みが変わる：$\ln k$ で当てはめると、小さい $k$ の相対誤差が強調されます。精度が重要な場合は、元の式のまま残差を最小にする非線形最小二乗法を使います
  • データの範囲の外に使わない：求めた式は、測定した温度範囲の中でだけ信頼できます
  • パラメータどうしの相関：$A$ と $E$ は強く相関していて、測定範囲が狭いと個々の値の誤差は大きくなります。温度範囲をなるべく広くとるのが有効です

表計算ソフトでは、SLOPE 関数と INTERCEPT 関数、またはグラフの近似曲線の機能で同じ計算ができます。
