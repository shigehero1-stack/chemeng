非線形方程式の解き方

化学工学でよく出てくる、手で解けない方程式を数値的に解く二分法とニュートン法を、コールブルックの式から管摩擦係数を求める例題と Python のプログラムで解説します。

手で解けない方程式

化学工学の計算では、未知数について式を解けない方程式がよく出てきます。

  • ある温度での混合物の沸点（気液平衡）
  • 流量から圧力損失を求めるときの管摩擦係数（コールブルックの式）
  • 理想気体でない気体の体積（3次の状態方程式）

このような方程式は、$f(x) = 0$ の形に直して、答えを少しずつ絞り込んでいく数値解法で解きます。代表的な2つの方法を紹介します。

二分法

$f(a)$ と $f(b)$ の符号が逆なら、その間に解があります。区間の真ん中 $m = (a + b)/2$ で $f(m)$ を計算し、符号が変わる側の半分に区間を狭める、という操作を繰り返します。

  • 長所：解が区間の中にあれば必ず収束する。プログラムが簡単
  • 短所：1回の計算で区間が半分になるだけなので、収束が遅い（10回で約1000分の1）

ニュートン法

今の近似値 $x_k$ での接線が $x$ 軸と交わる点を、次の近似値にします。

$$x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}$$
  • 長所：解の近くでは非常に速く収束する（1回ごとに正しい桁数がほぼ倍になる）
  • 短所：導関数 $f'(x)$ が必要。初期値が悪いと、発散したり別の解に行ったりする

実用上は、まず二分法でおおまかな範囲をしぼり、ニュートン法で仕上げる、という組み合わせもよく使われます。表計算ソフトの「ゴールシーク」も、同じように数値的に解を探す機能です。

コールブルックの式

乱流の管摩擦係数 $f$（ダルシーの摩擦係数）は、管の相対粗さ $\varepsilon/D$ とレイノルズ数から、次のコールブルックの式で求められます。

$$\frac{1}{\sqrt{f}} = -2\log_{10}\left(\frac{\varepsilon/D}{3.7} + \frac{2.51}{Re\,\sqrt{f}}\right)$$

$f$ が両辺にあるので、手では解けません。$x = 1/\sqrt{f}$ とおくと、$F(x) = x + 2\log_{10}\left(\dfrac{\varepsilon/D}{3.7} + \dfrac{2.51\,x}{Re}\right) = 0$ を解く問題になります。

例題：管摩擦係数を求める

レイノルズ数 $10^5$、相対粗さ $\varepsilon/D = 10^{-4}$ の管の摩擦係数を、コールブルックの式から求めてください。

import math

def colebrook(Re, eps_D, x=5.0, tol=1e-10):
    """コールブルックの式を x = 1/sqrt(f) についてニュートン法で解く"""
    for i in range(50):
        F = x + 2 * math.log10(eps_D / 3.7 + 2.51 * x / Re)
        dF = 1 + 2 / math.log(10) * (2.51 / Re) / (eps_D / 3.7 + 2.51 * x / Re)
        x_new = x - F / dF
        if abs(x_new - x) < tol:
            return 1 / x_new ** 2, i + 1
        x = x_new
    raise RuntimeError("収束しませんでした")

f, n = colebrook(1e5, 1e-4)
print(f"f = {f:.5f}（{n} 回で収束）")

実行結果：

f = 0.01851（4 回で収束）

初期値 $x = 5$（$f = 0.04$）から始めて、4回で収束しました。なめらかな管とみなしたブラジウスの式（管内の圧力損失の記事を参照）では $f \approx 0.0178$ となり、わずかな粗さで摩擦係数が 4% ほど大きくなることがわかります。

収束しないときのチェックポイント

  • 初期値が解から離れすぎていないか（物理的にありうる範囲から始める）
  • 解が複数ある方程式で、ほしい解の近くから始めているか
  • 導関数の式が正しいか（数値微分で確かめられる）
  • 繰り返しの上限回数と、収束の判定（差がどれだけ小さくなったら止めるか）を決めておく
