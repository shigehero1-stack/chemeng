線形計画法の基本

限られた原料や設備で利益を最大にする生産量を求める線形計画法の考え方を、2種類の製品の生産計画の例題で、図解法と Python のプログラムを使って解説します。

線形計画法とは

工場では、原料の量、装置の稼働時間、倉庫の容量など、さまざまな制約の中で、利益が最も大きくなる（または費用が最も小さくなる）ように生産量を決める必要があります。目的とする量と制約がすべて一次式で表せる場合、この問題を線形計画問題といい、その解き方を線形計画法（LP）といいます。

化学工業では、製油所の原油の配合と製品の生産計画、原料の配合、プラントの運転計画などに広く使われています。

問題の形

  • 決定変数：決めたい量（各製品の生産量など）
  • 目的関数：最大化（または最小化）したい量。決定変数の一次式
  • 制約条件：決定変数が満たすべき一次の不等式・等式。生産量は負にならない、という条件も含む
例題：2種類の製品の生産計画

ある工場で製品 A と製品 B を作っています。1 kg あたりの利益は A が 3 千円、B が 5 千円です。1 kg 作るのに必要な原料と装置の稼働時間、1日に使える量は次のとおりです。利益を最大にするには、それぞれ何 kg 作ればよいでしょうか。

製品 A製品 B1日に使える量
原料 [kg]23120
装置の稼働時間 [h]1270
利益 [千円/kg]35

生産量を A：$x$ kg、B：$y$ kg とすると、問題は次のようになります。

$$\text{最大化}\quad 3x + 5y$$
$$\text{制約}\quad 2x + 3y \le 120,\quad x + 2y \le 70,\quad x \ge 0,\quad y \ge 0$$

図解法：$x$-$y$ 平面に制約の境界線を描くと、すべての制約を満たす領域（実行可能領域）は多角形になります。目的関数の値が一定の線（$3x + 5y$ = 一定）を平行に動かしていくと、最適解は必ずこの多角形の頂点のどれかになります。そこで、頂点での利益を比べます。

from itertools import combinations

# 制約を a1*x + a2*y <= c の形で並べる（x >= 0, y >= 0 も含める）
cons = [(2, 3, 120),     # 原料
        (1, 2, 70),      # 装置の稼働時間
        (-1, 0, 0),      # x >= 0
        (0, -1, 0)]      # y >= 0
profit = lambda x, y: 3 * x + 5 * y

best = None
for (a1, b1, c1), (a2, b2, c2) in combinations(cons, 2):
    det = a1 * b2 - a2 * b1
    if det == 0:
        continue
    x = (c1 * b2 - c2 * b1) / det            # 2本の境界線の交点
    y = (a1 * c2 - a2 * c1) / det
    if all(p * x + q * y <= c + 1e-9 for p, q, c in cons):   # 実行可能な頂点だけ
        print(f"頂点 ({x + 0.0:.0f}, {y + 0.0:.0f}): 利益 {profit(x, y):.0f}")
        if best is None or profit(x, y) > profit(*best):
            best = (x, y)
print(f"最適解: 製品A {best[0]:.0f} kg, 製品B {best[1]:.0f} kg, 利益 {profit(*best):.0f}")

実行結果：

頂点 (30, 20): 利益 190
頂点 (60, 0): 利益 180
頂点 (0, 35): 利益 175
頂点 (0, 0): 利益 0
最適解: 製品A 30 kg, 製品B 20 kg, 利益 190

製品 A を 30 kg、製品 B を 20 kg 作ると、利益が最大の 19 万円になります。このとき原料も装置の稼働時間も使い切っています。利益の高い B だけを作る（35 kg で 17.5 万円）より、A と組み合わせたほうが得になるのは、B が装置の時間を多く使うためです。

変数が多い問題では

変数が2つなら図で解けますが、実際の問題では変数が数十〜数千になります。その場合は、頂点を効率よくたどって最適解を探すシンプレックス法などの方法を使います。表計算ソフトのソルバー機能や、Python の最適化ライブラリ（SciPy の linprog など）で解くことができます。

結果の読み方：どの制約が効いているか

最適解で使い切っている制約（この例では原料と装置の稼働時間の両方）を有効な制約といいます。有効な制約の量を少し増やすと、利益がどれだけ増えるかを表す値（シャドープライス、双対価格）を調べれば、「原料を買い足すべきか、装置を増強すべきか」を判断する材料になります。線形計画法は、答えを出すだけでなく、こうした経営判断にも役立ちます。
